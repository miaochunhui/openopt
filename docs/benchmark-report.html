Foundation extraction / 2026-10-10

Verification Is Not A Speedup Claim

No historical performance output was imported as current evidence. Independent test results are produced by python3 scripts/verify.py. The output records actual counts, failures, skips, dependency versions and whether CUDA is available.

Correctness Surface

The smaller scripts/iteration_gate.py smoke checks core API, projection, solver and constraint contracts. Full verification includes the complete migrated test suite and byte-level provenance checks. GPU skips mean that GPU cases were not verified; CPU passes must not be relabeled GPU passes.

Performance Qualification

Timing comparisons require the same objective and constraints, matched input hashes, explicit CPU/CUDA devices, warm-up separation, cold/hot timings, p50/p95, success rate, objective gaps, residuals and hardware/software versions. No KEEP verdict, universal acceleration, multi-GPU efficiency or production SLA is asserted by this extraction.

The imported research benchmark tools retain their original methodology. Use explicit output paths outside the repository and verify their artifacts before drawing conclusions. The old report-rendering and canonical-result pipeline was not migrated.
