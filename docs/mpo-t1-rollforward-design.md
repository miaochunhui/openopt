## 0. 先纠一个流传的说法：051 自己怎么说 roll-forward

| 出处 | 原话（要点） |
| --- | --- |
| §2 输入清单第 6 条 | "The estimate `r` for the roll-forward returns. The portfolios generated by the multi-period optimization are **sensitive to this choice**!" |
| §2 末 | "it is **hard to come with good roll-forward estimates** … we will assume that **`r = 0` throughout this paper**." |
| §7 结论 | 用**短周期 alpha 的缩放版**当 `r`：(a) 表现与 `r=0` **相似**，(b) 对 `r` 的取值**不敏感**。 |
| §7 结论 | 用**真实前视收益**当 `r`（但不放进 alpha 估计）：表现**大幅改善**，"**obviously this is not of practical use**"。 |

三条推论（这是本设计的出发点，不是我们的猜测）：

1. 论文正文自相矛盾：§2 警告"对 `r` 敏感"，§7 唯一真跑过的**可行**估计器结论是"**不敏感**"。
   以实跑为准 ⇒ 可行的 roll-forward 估计在论文自己的环境里就是 no-op。
2. 论文里"significant gains"只在**前视**（oracle）版本出现。任务描述里"好的 roll-forward 估计带来
   显著增益"这句，**在 051 原文里的成立条件是 oracle**，不能当作可行方案的先验。
3. 论文§7 那个可行估计器（"scaled short-term alpha"）**正是**本任务候选 (iii) 的同类。它已经被跑过、
   结论为空。重跑同一件事之前，先把量级账算清楚（§3）。

**oracle 与可行版差多少倍，可以直接算**：`r` 的可行估计只能是条件均值 `E[r|z] = IC·σ`，oracle 是实现值
本身 `~σ`。两者比 = `1/IC`。我们标定窗实测：`E|alpha_S1| = 4.22e-4`，而 30 分钟横截面收益
`E|r| = 0.798 × 2.5% × sqrt(30/240) = 7.05e-3` ⇒ 杠杆 **16.7×**。051 的 oracle 大幅改善与可行版为空
之间的落差，就是这 16.7 倍的信息量，**不是 roll-forward 机制本身的功劳**。

## 1. 在我们的公式里 roll-forward 是什么（精确化 + 一步关键化简）

051 eq(1) 的耦合式是**逐票**（不是标量财富增长）：`w² = (1+r) ⊙ w¹ + Δw²`。我们 SPEC §3 的动力学
`w^j − w^{j−1} − b^j + s^j = 0` 就是同一行取 `r = 0`。模型自洽的 `r` 只能是期限结构自己的阶段 alpha，
于是阶段 `j` 动力学右端的修正量是

    δ^j = w^{j−1} ⊙ alpha^j     （j=1 用**已知**的当前持仓 w⁰ ⇒ δ¹ 完全确定，无循环依赖）

**关键化简（这一步定死了整件事的量级）**：`b/s` 是自由变量，所以任一权重路径 `{w^j}` 在"修正后"与
"冻结"两套动力学下**都可行**，只是承载它的 `b/s` 差了正好 `δ^j`。给定路径，目标里的 alpha 项
`−alpha^j·w^j`、风险项、budget/box/T+1 行**逐位相同** —— roll-forward **唯一**改变的是**交易成本的原点**。
令 `c = cfg.buy_cost() + cfg.sell_cost()`（缺省 19bp），即得

    | Obj*_rollforward − Obj*_frozen |  ≤  c · ‖δ‖₁                                    (B)

二次冲击项额外贡献 `D(b+s)·δ + ½Dδ²`：`D_ii = 0.1×0.025/0.8 = 3.1e-3`，逐票 `(b+s) ~ 2.4e-4`
⇒ 系数 `7.4e-7`，比线性项的 `1.9e-3` 小 2500 倍，忽略（有单测口径）。

(B) 是**整个修正的经济含量的上界**，而且是**慷慨的**上界：它假设修正的全部 ℓ1 质量都被用在最优处。
真实的实现差更小 —— `w*` 已满足冻结问题的 KKT，改右端后的**改进**是二阶的（`½δ'Hδ`，
`H ⪰ γ(L/240)Σ_d + D` ⇒ 每纪元 ~2e-12 NAV，比 (B) 低 4 个数量级）。两条路同向，取 (B) 当判据。

## 2. 三个候选与取舍

| 候选 | 形式 | 凸性 | 判决 |
| --- | --- | --- | --- |
| (iii) **asset_drift**（=051 的 `r`，**唯一有实体的**） | 动力学右端加 `δ^j = w^{j−1} ⊙ alpha^j` | **保凸**（确定性右端平移） | 量级不足，见 §3 |
| (i) **alpha_growth** | `alpha^j × Π_{k<j}(1+g_k)`，`g_k = alpha^k·w^{k−1}` | 用上一纪元解/前一阶段线性化后保凸 | **实测 `Π(1+g)−1 = 1.51e-5`**（主轴均值）⇒ 这是对 alpha 的 **1.5e-5 相对缩放**；而 alpha 只按比例进目标 ⇒ 它与 `γ → γ/(1+G)` **观测等价**，而 `γ` 自己有 `{2,5,10,20}` 的敏感性轴。**在 γ 的可辨识噪声之内**，不是修正是幻觉。 |
| (ii) **budget_growth** | `1'w^j ≤ Π_{k≤j}(1+g_k)` | 保凸 | **结构性失效**：实测 gross `1'w = 0.144`（最极端格 0.603）对上界 1.0 ⇒ budget 行有 40–86% 松弛，**从不起作用**，把它的界挪 1.5e-5 等于没做。 |

**钦定主方案（若 GO）= (iii)**，因为它是 051 原文的 `r`、逐票、保凸，且 §1 的化简让它的效果可精确定界。
(i)/(ii) 不是"更弱的版本"，是**两个不同的量**（标量财富增长），而在权重口径下财富增长本就被 NAV
归一吸收 —— 这是它们量级更小一档的根本原因，不是巧合。

## 3. 量级账 → 判决（先算，算完才决定要不要写代码）

实测锚：真跑的 32 纪元 MPO 路径（seed 20260821，N=300，`calib_days=20`，eval day 20–23，
逐纪元求全阶段解后按 §1 口径算 `δ`）；`ann_vol`/`turnover` 取 24 seed 主轴基准
（`benchmark-results/mpo-t1-main-v2.json`）与敏感性基准（`mpo-t1-sensitivity-v2.json`）。

| 量 | 主轴 | `ic_mult=1.5, cost_mult=0.5`（修正最大的格） |
| --- | --- | --- |
| `‖δ‖₁`（逐纪元均值 / 最坏纪元） | 5.16e-5 / 1.09e-4 | 3.22e-4 / 4.99e-4 |
| 逐票最大 `|δ|`（均值 / 最坏） | 9.45e-6 / 1.89e-5 | 2.78e-5 / 4.30e-5 |
| `Π(1+g)−1`（全 horizon 期望财富增长） | 1.51e-5 | 1.58e-4 |
| `c = buy+sell` | 1.9e-3 | 9.5e-4 |
| (B) 每纪元目标上界 | 9.80e-8 | 3.06e-7 |
| 年化（×1920 纪元） | 1.88e-4（**1.9bp/年**） | 5.88e-4（**5.9bp/年**） |
| `ann_vol` | 1.764e-2（实测均值） | 3.111e-2（**保守取** ic=1.5 格；实际该格 gross 大 4.2× ⇒ 真 vol ≈7.4e-2） |
| **ΔSharpe 上界** | **0.0107** | **0.0189**（用真 vol 则 0.0080） |
| A/B 分辨力（Iter40 实测 CI 半宽） | 0.01975 | 0.01975 |
| `|δ|_max / no-trade band(2e-4)` | **0.047** | **0.139** |
| `‖δ‖₁ / 每纪元换手` | 0.49%（换手 1.06e-2） | 0.19%（换手 1.70e-1） |

**逐阶段分布**（主轴，`‖δ^j‖₁`）：stage0 `5.13e-5` / stage1 `3.13e-7` / stage2 `2.39e-10` /
stage3 `2.25e-18`。即 **99.4% 的修正集中在 stage 1**，`j≥2` 的阶段 alpha 被 `rho^delta` 压到数值零
⇒ **`r=0` 对 stage 2–4 不是近似，就是模型自己的后验均值**（到 5 位以上）。051 的 `r=0` 在我们这里是
自洽解，不是省事。

**钦定判据（写死在 `rollforward._verdict`，两条必须同时成立才判 negligible）**：
(1) `sharpe_bound < 0.01975`（先验天花板低于 A/B 分辨力 ⇒ 即使为真也测不出来）；
(2) `band_ratio < 1`（逐票最大修正低于 no-trade band ⇒ 触不到市场）。
两格都过 ⇒ **NO-GO**。诚实标注：最极端格用**故意保守**的 vol 时上界 0.0189 vs 门槛 0.01975，**只余 4% 余量**；
换成同一探针实测的 gross 推 vol（4.2× 放大）则余量 2.5×。两种口径都在门槛内，但边际很薄，写在这里备查。

**证伪/翻案条件（量级如何随参数走，可直接代公式）**：(B) 里 `‖δ‖₁ ∝ IC²`（`w∝IC`、`alpha∝IC`），
`ann_vol ∝ IC` ⇒ **`sharpe_bound ∝ IC × c`**。故翻案需要：(a) IC 提高 ~2× 且成本不降（真实 A 股高频
截面 IC 未必够）；或 (b) A/B 分辨力提高（seed 数 ×4 把 CI 半宽压到 0.01 以下，或换低噪对照设计）；
或 (c) 换到 `w_max`/budget **真正 binding** 的环境（届时 (ii) 从"结构性失效"变成有效，量级重算）。
任一条兑现，用 `rollforward_magnitude_bound` 重跑本表即可，不必重推设计。

## 4. 预注册 A/B（**GO 才跑**，判据先写死，跑完不许改）

- 设计：配对 seed（同市场路径同执行层同 `fit_term_structure` 产物），`mpo` vs `mpo_rollforward`，
  差异**只**来自动力学右端的 `δ^j`（候选 iii，`δ¹` 用已知 `w⁰`，`δ^{j≥2}` 用**上一纪元解**平移一位，
  measurable ⇒ 保凸、无循环）。
- 单元格：主轴 24 seeds；敏感性 `ic_mult ∈ {1, 1.5}` × `cost_mult ∈ {0.5, 1}` 各 8 seeds
  （§3 已证复利效应在 `ic=1.5, cost=0.5` 最大）。
- 主指标：净年化 Sharpe 配对差（bootstrap 1e4 95% CI + 配对 t + 胜率 + Hedges g）；
  次指标：日均换手、成本四分解、`‖δ‖₁` 台账、T+1 违规=0。
- **证伪判据**：(a) `ic=1.5,cost=0.5` 格 ΔSharpe 的 CI 含 0 ⇒ 判空，本方向封版；
  (b) 任一格 ΔSharpe 显著为负 ⇒ 定罪为"把噪声当漂移"，回 `r=0`；
  (c) `‖δ‖₁` 台账与 §3 表偏离 >3× ⇒ 先查接线，判据暂缓。

## 5. 诚实的风险清单

1. **与 alpha 衰减的双重计数（最实的一条）**：99.4% 的 `δ` 来自 `δ¹ = w⁰ ⊙ alpha_S1`，而
   `alpha_S1` **正是** Iter42 延迟成本层（`docs/mpo-t1-delaycost-design.md`）已经在给 stage-1 买卖
   定价的同一个 `[N]` 向量。两者**同向**（都压"已持有的正 alpha 票"的买入）⇒ 同时开启就把同一个
   30 分钟预测用了两次。若将来 GO，A/B 必须与 `mpo_delayaware` **互斥**或加一格三向对照。
2. **与加性风险缩放的交互**：风险项按 `(L_j/240)` 加性缩放、不含财富增长；候选 (i) 只放大 alpha 不放大
   风险 ⇒ 引入 `γ_eff = γ/(1+G)` 的不一致。`G = 1.5e-5` 使这条在数值上无害，但它说明 (i) **不是修正
   而是重参数化**，这也是 §2 判它死的原因（不是"太小"，是"不是那个东西"）。
3. **δ 的符号是押在最短周期 alpha 上的**：`δ` 与 `alpha_S1` 同号，而 30 分钟信号是三条里最不可靠的
   （Iter40 实测 `κ[0,:]≈0.97`，但那是标定窗内）。可行估计的信噪比只有 oracle 的 1/16.7（§0），
   把它写进**约束**（而非目标）意味着一旦符号错，QP 是**被迫**按错方向平移，没有成本项挡一挡。
   这是"即使量级够也应先做目标侧修正（延迟成本）而不是约束侧"的独立理由。
4. **本 leg 明确不做的事**：不动 `execution.py`（bar 末成交口径）、不动动力学、不加策略臂、不进
   `DEFAULT_STRATEGIES`。`rollforward.py` 不被任何生产模块 import（机检：`test_rollforward.py::
   TestIsolation`）。
5. **上界不是估计**：§3 给的是**上界**，不是"效果约 1bp"的预测。真实效果按二阶口径低 4 个数量级
   （~2e-12/纪元）。任何人拿 §3 的 1.9bp/年 当"预期收益"都是误读。
