openopt Dense QP Design / v2

The independent OpenPO portfolio foundation is preserved. A separate experimental domain-neutral real dense convex QP/LP core now lives in src/openopt/qp.py.

Contract

Minimize 0.5 x' P x + q' x, with l <= A x <= u. Owned prepared workspaces, strict CPU/CUDA requests, float32/float64 and approximate KKT-based termination are implemented. The default path remains Cholesky; an explicit triangular option permits controlled comparison and immediate reversal.

Boundaries

This is not sparse, conic or mixed-integer optimization. No infeasibility/unboundedness certificate, universal minimize API, presolve, automatic routing or commercial qualification is advertised. Existing openpo objects retain identity.

Evidence

Current measured report separates model-cold and prepared timings, CPU/GPU pairs, failures, GPU/cgroup telemetry and Nsight profiles. Source and result hashes are retained externally; no private data or credentials are copied.

Implementation And Limits

Full design and measurement contract / Remaining work. Project code is 0BSD; third-party dependencies retain their own terms. GPU benefit is workload-dependent.
