Foundation extraction / 2026-10-10

openopt

A GPU-accelerated optimization project, starting from the existing OpenPO portfolio implementation. This extraction is not a general-purpose optimizer release and does not redesign the algorithms.

Architecture

src/openpo owns the unchanged implementation: low-rank factor models, projections, batched solvers, linear constraints, exact references, portfolio adapters, multi-period research and certification service libraries. src/openopt reexports the same public objects, preserving identity and compatibility without copying solver logic.

Generalization Boundary

The current API still names alpha, holdings and portfolio risk. The next stage must define a domain-neutral quadratic operator and LP/QP contract, then move portfolio semantics behind adapters. A general model must not disguise portfolio assumptions with renamed classes.

Correctness Before Speed

The independent smoke gate and full migrated test suite verify numerical behavior and API compatibility. They are not performance gates. Continuous reference comparisons remain OSQP/Clarabel; future discrete comparisons must use SCIP/HiGHS under equivalent formulations and budgets.

Provenance validates the imported bytes in the initial Git commit, while regression tests validate current code. The exact-snapshot check is a separate tool, not a permanent ban on independent algorithm changes. Wheel validation checks the module set and solves a synthetic problem from an isolated install.

The first independent fix closes a durable-service publication race. Successful terminal readers validate the result and enforce its divergence circuit before reporting readiness; admission also rechecks the circuit after online solving. Fenced rejected results still cannot open circuits. Numerical solvers and their parameters are unchanged. An audited reset fences replay of the same divergence evidence inside the circuit transaction, while new divergence evidence may still open the route.

Maintenance And Release

Private deployment, proprietary data, credentials, commercial PDFs and historical results are excluded. Results and logs stay outside the worktree. The rights holder must decide licensing before an open-source release.
