Openopt / v3 通用 QP 设计

独立的通用 QP/LP 实验核心，保持 OpenPO API 身份。 默认稠密 ADMM；可选残差平衡 rho、同形状批量和稀疏/矩阵自由 CG。

正确性边界

严格显式设备、owned tensor workspace、原坐标残差与非有限失败。 批量逐项冻结状态；CG 核验真实内层残差、不稠密化。稀疏调用者必须声明 PSD， 抽样探测不证明凸性。独立候选/方向检查仅是数值证据，不是精确证明。

实测与限制

v3 同源报告展示收益与反证。 没有成熟锥/整数求解器、可靠不可行方向生成、通用 minimize 或商用资格。 当前性能门重新检查封存源、题目、解向量、参数、状态、对照与 profile。
