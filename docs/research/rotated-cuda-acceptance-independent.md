## Bounds

The portable fixture is explicitly synthetic, unexecuted CUDA-shaped
coordinator data. It does not become actual GPU evidence because a gate accepts
it. Its thirteen identities are declared independently, including all three
negative candidates and their unmutated baselines. Fraction checks compute the
original represented residuals, cone signs/small head, per-block signed
complementarity, PSD range and signed gap. Projection references use a
1100-digit Decimal SOC isometry, not the auditor's direct RSOC elimination.
No producer, optimizer, Torch or NumPy import or solve is used.

Execution negatives exercise complete audit() with relocated controlled
synthetic status/submitted records and coordinated refreshed pins, not a
substitute gate. Numerical negatives
exercise the real replay_sidecar after saving and reloading changed bytes.
Every observation records actual acceptance or exact failure. Expectations
remain reject; no xfail, threshold relaxation or retry hides a false accept.
Initial coverage is bounded to full thirteen, config/model/property/dtype,
placement, baseline, tiny head, settings environment, actual specification,
owner identity, digest and strict integer types. New findings are not general
optimizer or arbitrary adversarial-runtime guarantees.

Historical CLI is separate, explicitly opted in with external caller pins.
It runs seal, accept and a wrong-pin negative through the actual clean tool,
using the recorded 13-case CUDA archive. This is a later CPU mathematical and
archive read, not new GPU execution or remote attestation. No commercial,
performance, 76-case, arbitrary conic or final-release claim is made.

## Reproduction

Portable default needs no historical 3FS data. From this independent tree:

```bash
sudo -n -u infra env CUDA_VISIBLE_DEVICES=-1 PYTHONDONTWRITEBYTECODE=1 \
  /hf3fs-jd/data/tmp/openopt-validation-env/bin/python \
  tests/test_rotated_cuda_acceptance_independent.py --artifact-dir /absolute/external/root
```

For historical execution also set OPENOPT_FIXED13_INDEPENDENT_HISTORY=1,
OPENOPT_FIXED13_INDEPENDENT_PINS to the externally reviewed pins.json and
OPENOPT_FIXED13_INDEPENDENT_PINS_SHA256 to its separately supplied hash.
The runner freezes source/test bytes, preserves pytest/JUnit/observations and
receipt.json outside the repository. Missing opt-in skips only the historical
node; missing required pins after opt-in fails loudly.

An explicit OPENOPT_FIXED13_GATE_SHA256 selects a newly reviewed frozen target
in a separate tree; absent that pin, the original gate bytes above are required.
It does not waive source, model, numerical or execution gates.
