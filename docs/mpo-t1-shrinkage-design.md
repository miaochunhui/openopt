# MPO-T1 P1 · 稳健 alpha 收缩设计（Iteration 40 leg 1）

参考 Axioma 003/007（robust alpha shrinkage）：**低置信度的周期把 alpha 压得更狠**。本文档是
`src/openpo/mpo/shrinkage.py` 的权威设计源；leg 1 只落估计器 + 包装器 + 单测，**不接线**（配置
开关与基准新策略在 leg 2，设计评审通过后再动 `config.py`/`strategies.py`/`backtest.py`）。

> **状态（2026-08-23）**：leg 1 + leg 2 均已完成，A/B **判决=中性**，模块已降级为 opt-in 研究件。
> 结论见文末《实测判决》一节；§3 的预注册判据与 §4 的风险清单原样保留（不回改，供对照）。

## 0. 与 ridge 的分工（务必区分，勿混为一谈）

| | ridge（SPEC §2 step 3，已在册） | κ 收缩（本设计） |
| --- | --- | --- |
| 收缩对象 | **B 的估计**（估计误差） | **决策时刻的 alpha 幅度**（决策损失） |
| 收缩目标 | telescoping 先验 `B0`（结构先验，非 0） | **0**（无技能先验） |
| 惩罚强度 | `lam = ridge_lambda * n_samples`，与样本量无关 | 由信噪比 `t = IC/σ(IC)` 定，样本越少收缩越狠 |
| 作用面 | 每分段一行 `B[s,:]`（多元回归） | 逐 (分段 s, 信号 k) 一个标量 `κ[s,k]` |

两层串联：`alpha = (κ ⊙ B_ridge) · z`。ridge 决定"B 长什么样"，κ 决定"敢下多少注"。

## 1. 估计器（committed 公式）

逐 (分段 s, 信号 k)，只用标定窗 `[0, calib_days)`，沿用 `fit_term_structure` 的同一套无前视守卫
（`tau + b_s < calib_days*240` 才取样）与同一套 winsorize：

1. **逐纪元截面 IC**：`ic[s,k,e] = spearman(z_e[:,k], winsor(r_seg[s]_e))`，只用
   有限值且 `p0>0` 的票，可用票数 `< 3` 的纪元丢弃。
2. **点估计**：`IC[s,k] = mean_e ic[s,k,e]`，可用纪元数 `E[s,k]`。
3. **重叠折减**（长周期最关键）：纪元间距 30 分钟，而分段 s 的窗口长 `len_s = b_s - a_s`
   分钟，相邻纪元的已实现收益高度重叠 ⇒ 独立观测数远小于 `E`：

       m_s     = max(1, len_s / 30)                 # (0,30]→1, (30,240]→7, (240,2400]→72
       E_eff   = E / m_s

4. **抽样方差**（经验方差 + 解析下界取大，保守）：

       v_emp   = var_{ddof=1}(ic[s,k,:])            # E < 2 时取 0
       v_ana   = (1 - IC^2)^2 / max(n_med - 3, 1)   # n_med = 可用票数中位数；Fisher-z 近似下界
       sigma2  = max(v_emp, v_ana) / E_eff

5. **收缩系数（本设计钦定形式）**：

       kappa[s,k] = IC^2 / (IC^2 + sigma2)  =  t^2 / (1 + t^2),   t = IC / sigma

6. **应用**：`B_shrunk = kappa ⊙ B`（逐元素），其余（`rho`/`seg_bounds`/`decay_mult`）不变。

**推导草图**：设该 (s,k) 的总体 IC 为 θ，观测 `IC = θ + ε`，`ε ~ N(0, sigma2)`；先验
`θ ~ N(0, tau2)`（缺省"无技能"）。高斯共轭 ⇒ 后验均值 `E[θ|IC] = tau2/(tau2+sigma2) · IC`。
决策时刻 alpha 与预测-实现相关度成正比，故对 alpha 做 MSE 最优的再缩放系数与之同形，即
`κ = tau2/(tau2+sigma2)`。经验贝叶斯：`E[IC^2] = tau2 + sigma2`，矩估计给
`tau2 = (IC^2 - sigma2)_+`（正部 James-Stein，`κ = (1 - sigma2/IC^2)_+`）。**本设计改用更平滑的
插值先验 `tau2 = IC^2`**，得上式：两者在 `t >> 1` 时到 `O(t^-4)` 完全一致，只在低信噪区分道——
矩估计在 `t = 1` 处硬截断到 0（±1 SE 的抖动就让 κ 在 0 与 0.5 间跳），平滑式连续单调、跨 seed 稳。

**退化行为**（全部有单测）：

- `E = 0`（该 (s,k) 一个可用纪元都没有）⇒ `sigma2 = +inf` ⇒ `κ = 0` ⇒ alpha ≡ 0 ⇒ QP 不新增交易。
  **这是唯一允许的兜底**，且写进 `IcStats.notes['degenerate_cells']` 台账，不静默。
- `sigma2 → 0`（估计确定）⇒ `κ → 1` ⇒ **逐位等于**被包装模型（单测 bitwise 校验）。
- `IC = 0` ⇒ `κ = 0`；`|IC|` 越大 κ 越大，σ 越大 κ 越小（单调性单测）。
- κ 与 IC 符号无关（只缩放幅度）：符号错的信号是 B 的问题，不是 κ 的职责。

## 2. 应用点：`ShrunkTermStructureModel`（组合而非继承）

包装已拟合模型，实现与 `TermStructureModel` **同名同签名**的消费面
（`.B` / `.rho` / `.seg_bounds` / `.decay_mult` / `.effective_rho()` / `.stage_alphas(z, grid)` /
`.diagnostics`），`stage_alphas` **不重写数学**：内部持一个 `B = κ⊙B_base` 的 `TermStructureModel`
并转发，因此运算顺序与基线逐位一致（κ=1 ⇒ bitwise 相同）。

- `.B` 已是收缩后的矩阵 ⇒ 用 `.B` 的三条基线（`SingleSignalStrategy` / `FixedWeightStrategy` /
  `InformedTradingStrategy`）若被喂包装器也自动一致，无需改它们。
- `.diagnostics` 是**新对象**（复制基线诊断 + `notes['kappa']`/`ic`/`ic_se`/`E_eff` 台账），
  不改写基线模型的诊断（包装器对 base 只读）。
- leg 2 接线只需一个 config 开关：`shrink_term_structure(model, market, signals, cfg)` 出包装器，
  塞进现有 `_strategy_pool` 的 `ts_model` 位；`stage_alphas` 数学零改动。

## 3. leg 2 预注册 A/B（先写死，跑完不许改判据）

- 设计：**配对 seed**（同 seed 同市场路径同执行层），`mpo`（κ off）vs `mpo_shrunk`（κ on），
  两者共用同一 `fit_term_structure` 产物（κ 只是外挂一层），差异纯来自 κ。
- 单元格：主轴 24 seeds（`ic_mult=1`）+ 敏感性 `ic_mult ∈ {0.5, 1}` × 8 seeds
  （低 IC 区是 κ 最该起作用的地方）。
- 主指标：净 Sharpe 的配对差（seed 层 bootstrap 1e4 95% CI + 配对 t + 胜率）；
  次指标：日均换手、成本四分解、κ 表本身。
- **预期方向**：`ic_mult=0.5` 处 κ 有帮助（ΔSharpe > 0 且 CI 不含 0 = 赢）；`ic_mult=1` 处近中性
  （|ΔSharpe| 小、CI 含 0 可接受）；换手必须下降（否则 κ 没咬住，见 §4）。

## 3.5 leg 1 实测锚（跑完落此，供 leg 2 前先自证有分辨力）

缺省合成市场（`SynthConfig(n_days=25)`，seed 20260821，`calib_days=20`）实测 κ 表：

| 分段 | E / E_eff | κ（ic_mult=1，三信号） | κ（ic_mult=0.5） |
| --- | --- | --- | --- |
| (0,30] | 159 / 159 | 0.993 / 0.975 / 0.965 | 0.978 / 0.548 / 0.818 |
| (30,240] | 152 / 21.7 | 0.741 / 0.373 / 0.690 | 0.526 / 0.038 / 0.376 |
| (240,2400] | 80 / 1.1 | 0.062 / 0.120 / 0.000 | 0.043 / 0.096 / 0.002 |

即：短段几乎不收缩、中段腰斩、**长尾段被压到 ~0.06**，且低 IC 档整体收得更狠 —— 方向正是
Axioma 003/007 要的"低置信周期压更狠"，且证伪条件 (a)(b) 都没触发（有分辨力）。

已知真值的恢复研究（`tests/mpo/test_shrinkage.py::TestRecovery`，seeded）：弱信号
（总体 IC 0.03，8 纪元×60 票）alpha 的 MSE 从 `1.745e-3` 降到 `9.192e-4`（**比值 0.527**，
平均 κ=0.367）；强信号（IC 0.30，32×200）κ=0.998、比值 1.009（基本零影响）。

## 4. 诚实的风险与证伪条件

1. **与 ridge 的双重收缩**：两层都在压 alpha 幅度，叠加可能过收缩 ⇒ 欠交易。leg 2 A/B 冻结
   `ridge_lambda` 只开关 κ，把交互隔离在"给定 ridge 下 κ 的边际效应"；κ 表与换手同时上台账。
2. **κ 与 B 同窗（样本内乐观）**：IC 用的是同一标定窗（虽然用原始 z 而非拟合值，仍是同窗），
   σ 被低估 ⇒ κ 偏大 ⇒ 收缩偏弱。方向是保守的（最坏退化为 no-op），故 leg 1 不切窗
   （`calib_days=20` 本就紧）；leg 2 留一格"半窗估 κ"的敏感性作为证伪腿。
3. **重叠折减 `m_s` 是 Newey-West 的粗替身**：过狠会把 (240,2400] 的 alpha 压到 ~0，使 MPO 退化
   成单期策略。§3.5 实测 `κ[2,:] ≈ 0.06` ⇒ **此风险已经在飞**：缺省 `calib_days=20` 只给长尾段
   ~1.1 个有效独立观测，κ 几乎必然把它清零。若 MPO 相对单期的优势正来自长尾段，κ 在
   `ic_mult=1` 处就可能不是中性而是负的。leg 2 必须同时看 `stages{1,2,4}` 轴：若 `mpo_shrunk`
   的表现塌到 `stages=2` 的水平，即定罪本折减过狠（备选：`m_s = sqrt(len_s/30)`，或用更长的
   标定窗把 E_eff 抬上去）。
4. **单变量 IC vs 多元 B 不匹配**：信号间相关约 0.3，单变量 IC 高估边际贡献 ⇒ κ 偏乐观。
   备选（若 A/B 证伪本式）：改用逐分段拟合值的复合 IC（`diagnostics.seg_ic` 已有）派生
   `κ[s,:]` 同值。
5. **κ 自身的估计噪声在"中等 IC + 小样本"格里会倒亏**：κ 与 `B̂` 同号相关（`B̂` 偏大时 κ 也偏大），
   会放大 `B̂` 的噪声。恢复研究实测：总体 IC 0.15、仅 8 纪元×60 票时 MSE 比值 **1.374（变差）**，
   而 IC 0.02 时 0.458、IC 0.05 时 0.942。含义：κ 只在"潜在收益 >> κ 自身噪声"的低信噪区赚钱，
   中间区可能小亏。这也是 §3 预期把 `ic_mult=1` 写成"近中性"而非"必赢"的实测依据。
6. **证伪条件**：(a) 缺省配置下 κ 表几乎全 1 ⇒ 估计器没有分辨力，A/B 必然为空，本设计无价值
   （§3.5 已排除）；(b) κ 表几乎全 0 ⇒ 策略停止交易，公式或 `m_s` 定得过狠；
   (c) `ic_mult=0.5` 处 ΔSharpe 显著为负 ⇒ 方向判断错，回到 §4.4 备选或放弃本 P1。

## 实测判决（2026-08-23 · leg 2 A/B）

预注册判据（§3）跑完未改，结果如下（产物 `benchmark-results/mpo-t1-shrinkage-main.json` /
`benchmark-results/mpo-t1-shrinkage-sensitivity.json`，指标恒为净年化 Sharpe 的配对差
`mpo − mpo_shrunk`，正 = 不收缩更好）：

| 单元格 | ΔSharpe | bootstrap(10⁴) 95% CI | 配对 t 的 p | 胜率 | Hedges g |
| --- | --- | --- | --- | --- | --- |
| **主轴** 24 seeds（`ic_mult=1`） | **+0.0078** | [−0.0118, +0.0277] | **0.464** | 50% | 0.15 |
| `ic_mult=0.5`（8 seeds） | +0.069 | [−0.186, +0.389] | 0.678 | 50% | 0.14 |
| `ic_mult=1.0` | −0.000 | [−0.036, +0.035] | 0.991 | 50% | −0.00 |
| `ic_mult=1.5` | +0.000 | [−0.020, +0.023] | 0.981 | 38% | 0.01 |
| `stages=1` | +0.024 | [−0.026, +0.073] | 0.401 | 63% | 0.28 |
| `stages=2` | +0.010 | [−0.023, +0.053] | 0.659 | 38% | 0.15 |
| `stages=4` | −0.000 | [−0.036, +0.035] | 0.991 | 50% | −0.00 |

- **主轴 = 中性**：ΔSharpe +0.0078，CI 跨 0，p=0.464，胜率恰好 50%，效应量 0.15（方向 mpo 略优，
  但不显著）。κ 既没赢也没输，是个 no-op 量级的扰动。
- **预注册的"低 IC 区该赢"未获确认，且方向相反**：`ic_mult=0.5` 处 ΔSharpe **+0.069**（mpo 更好），
  CI [−0.186, +0.389] 极宽、p=0.678 ⇒ 该格无分辨力，但点估计方向与 §3 预期相反。这是本设计
  最核心的一条预注册假设，**如实记为未确认**（也未到 §4.6(c) 的"显著为负"证伪线）。
- **§4.3 的重叠折减风险未兑现**：`stages{1,2,4}` 轴 ΔSharpe 分别 +0.024 / +0.010 / −0.000，
  `mpo_shrunk` 在 4 阶段处并未塌到 2 阶段的水平 ⇒ 长尾段 κ≈0.06 **没有伤到多阶段增益**。
  推论（比"折减定得对"更可能）：**本合成环境里长尾段本身的边际 alpha 就极微小**，把它清零几乎
  无代价——这同时解释了主轴为何中性。
- **T+1 违规 = 0**（主轴 24 seeds × 9 策略 + 敏感性 6 格 × 8 seeds × 9 策略，共 648 条记录）。
- **未跑的腿，如实声明**：§4.2 计划的"半窗估 κ"敏感性格**没有发**。理由：该格是用来查"κ 偏大 ⇒
  收缩偏弱"的，而主轴既然中性、`ic_mult` 轴又无分辨力，把 κ 调得更狠只会在同一个 no-op 邻域里
  再取一个点，ROI 不足；真要重估，前提是换到真实数据（见判决末句），届时连同这一格一起补。

**判决**：κ 层加在 ridge 先验收缩**之上**是**二次收缩**，§4.1 预言的"双重收缩"以**中性**兑现——
ridge 已经把 alpha 幅度压到位，κ 再压一遍既榨不出增益也没造成欠交易。故本模块**降级为 opt-in
研究件**（从 `backtest.DEFAULT_STRATEGIES` 移出，进 `OPT_IN_STRATEGIES`，代码/单测/κ 台账全部保留，
`run_seed(strategies=["mpo", "mpo_shrunk"])` 仍可复跑）。**真实数据上值得重测**：真实 IC 非平稳、
样本更噪，σ 更大 ⇒ κ 的用武之地比合成环境大，这条留给集群腿（前置件同 Iter39 的 d/m/t_alpha 三族拆分）。
