# Release Completion Contract

The user requested completion of commercial qualification, general capability
and online publication on 2026-10-10. These are three independent gates, not a
promise of universal solver dominance.

## General Capability

LP and convex QP must have original-coordinate numerical acceptance, reliable
failure/unknown status, generated and independently checked infeasibility or
recession evidence where available, objective-gap qualification, scaling and
representative sparse data. SOC and integer scopes require explicit contracts
and independent references. Limited integer enumeration is not a general
MILP/MIQP engine. Third-party CPU backends are labeled, never silently selected
for an explicit GPU request.

Production qualification additionally needs presolve/refinement, broad model
coverage, release/runtime compatibility, cold/prepared/changing-data semantics,
failure and tail distributions, numerical perturbation and long-run testing.
Implemented interfaces alone do not satisfy these requirements.

## Commercial Qualification

Use installations and licenses authorized for this purpose. Never acquire,
copy, print or alter license material to turn a missing baseline green.
Installation discovery is not authorization. Run identical immutable models,
paired resource configurations and independently verify original-model
accuracy, status, certificates and optimality gaps. Include attempts, failures,
unsupported cases, controls and tail latencies. A qualified test stratum does
not establish universal superiority.

## Publication

Use the existing managed publication chain and identity. Add only the Openopt
scope with an explicit reversible source/entry change. Do not expose internal
paths, host identity, proprietary data, credentials or license material.
Commit source before publication. Verify deployed source/version and content
through the existing authorized readback. Browser display and machine readback
are separate evidence. A local HTML or Git commit is not online publication.

## Progress

Each gate stays incomplete until its required evidence can be reread and
independently reproduced. GPU jobs remain bounded to three RTX PRO 4500 cards;
only the coordinator submits. Eight disjoint development seats are used with
the real native concurrency limit disclosed. This contract does not relax
the project's strict device, 0BSD or credential boundaries.
