# QP Campaign Handoff

## Conclusion And Scope

All eight independent scoped seats were integrated. The native tool permits
six simultaneous agents; two seats were refilled after completion. No Flash
pool was enabled. This campaign is not completion of a world-leading general
optimizer or proof of commercial parity.

The implementation adds optional adaptive rho, same-shape dense batching,
sparse/matrix-free CG, independent numerical candidate/direction checks, a
synthetic stress corpus, solver comparisons and sealed replay acceptance.
Nonfinite objective/residual false success was repaired. Default paths remain
available; optional methods do not enable automatic routing.

The GPU batch ladder contains eight copies of one problem at each size,
compared with sequential solves on the same GPU. Cold median speedup is
2.53x--4.58x; prepared is 2.39x--4.54x. Model validation, transfers and host
outputs are timed, but independent CPU quality checking is outside timing.
This is not a heterogeneous corpus or commercial speedup. Adaptive 1024 is
within control noise. Sparse 128 is slower and validation parity is unverified.
